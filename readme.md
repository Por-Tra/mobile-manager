# Mobile Manager

Mobile Manager est une application android qui permet de gérer son temps d'écran mais par la manière forte.
L'application permet de bloquer l'accès à certaines applications pendant une période définie par l'utilisateur et aussi de limiter le temps d'écran sur certaines applications.
Il peut aussi définir des périodes de temps d'écran autorisées par exemple entre 00h et 06h du matin, impossible de lancer une application (sauf le reveil et l'horloge) pendant cette période.

Ensuite l'application possède un système anti-doomscrolling qui permet de limiter le temps passé sur certaines applications : tiktok car le but est le doomscrolling.
Mais il y a un point encore plus important est difficile à mettre en place, c'est le fait de devoir supprimer complétement la partie réels et autres de instagram pour éviter le doomscrolling. L'application permet donc de supprimer cette partie de l'application instagram et de ne laisser que la partie publication et messagerie.

Le mode verrouillage strict
Quand l'utilisateur lance une session de concentration, les applications sélectionnées sont bloquées jusqu'à la fin.
- Pas de bouton « encore 5 minutes ».
- Pas de désactivation immédiate depuis Mobile Manager.
- Un délai de réflexion avant une éventuelle dérogation.
- Une indication claire de l'heure de fin.
Le but est de supprimer la négociation permanente avec soi-même, sans prétendre rendre le téléphone impossible à déverrouiller.

Le détecteur de sessions de doomscrolling
Ne limite pas seulement le temps cumulé. Détecte aussi les longues sessions continues.
Exemple :
- 5 minutes sur Instagram pour répondre à un message : aucun problème.
- 25 minutes de défilement continu : blocage du contenu distrayant.
- Retour à la messagerie : toujours autorisé.
Tu peux même ajouter un petit écran de transition après une durée définie, afin de casser le geste automatique.

Un tableau de bord utile, pas culpabilisant
Montre :
- Le temps d'écran par application.
- Le temps passé dans les flux distrayants, si détectable.
- Le nombre de sessions interrompues.
- Le respect des objectifs.
- L'évolution hebdomadaire.
Évite les messages culpabilisants. L'objectif est de mesurer si l'outil aide réellement l'utilisateur, pas de lui faire honte lorsqu'il dépasse une limite.
