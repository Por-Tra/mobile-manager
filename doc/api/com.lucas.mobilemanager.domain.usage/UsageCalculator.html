UsageCalculator object

Package: com.lucas.mobilemanager.domain.usageModule: :core:domainSource: UsageCalculator.kt

Time spent in the foreground, computed from resume/pause events.

Events must cover a little more than the wanted period (a few hours before midnight) to find the resume of an app left open across midnight.
