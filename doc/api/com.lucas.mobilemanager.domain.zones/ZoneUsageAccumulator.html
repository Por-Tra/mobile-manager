ZoneUsageAccumulator class

Package: com.lucas.mobilemanager.domain.zonesModule: :core:domainSource: ZoneTracking.kt

Measures the time spent in zones (Reels, Shorts…) for daily quotas.

The time between two consecutive “in the zone” observations is counted, capped at maxGap: a frozen screen or a suspended service does not count indefinitely. Time is split at midnight to be attributed to the right day.
