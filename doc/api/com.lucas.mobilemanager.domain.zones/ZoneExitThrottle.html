ZoneExitThrottle class

Package: com.lucas.mobilemanager.domain.zonesModule: :core:domainSource: ZoneTracking.kt

Avoids loops when leaving a zone: at most one action every minInterval, and fallback to the block screen if the zone persists after maxAttempts actions (detector clicking at the wrong place, app ignoring back…).
