ZoneUsageRecorder class

Package: com.lucas.mobilemanager.zonesModule: :appSource: ZoneUsageRecorder.kt

Time spent in zones, for quotas. Observations accumulate in memory and are written to zone_usage in batches (every FLUSH_EVERY of counted time, and when the app is left): no disk write at every check.
