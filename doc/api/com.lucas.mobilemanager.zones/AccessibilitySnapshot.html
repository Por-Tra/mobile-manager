AccessibilitySnapshot class

Package: com.lucas.mobilemanager.zonesModule: :appSource: ZoneEnforcer.kt

Flat snapshot of the accessibility tree (reading order, with depth). Off-screen nodes (tabs kept in memory by Instagram…) and their children are skipped, except for the diagnostic mode, which shows them marked as invisible.
