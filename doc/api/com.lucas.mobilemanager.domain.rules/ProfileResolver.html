ProfileResolver class

Package: com.lucas.mobilemanager.domain.rulesModule: :core:domainSource: ProfileResolver.kt

Determines which rules apply now and in which priority order:

  1. running strict session;
  2. manually activated profile;
  3. active scheduled profiles, by decreasing priority then increasing id;
  4. global rules.
