ScheduleEvaluator object

Package: com.lucas.mobilemanager.domain.timeModule: :core:domainSource: ScheduleEvaluator.kt

Evaluates time ranges in a given time zone.

Daylight saving changes: local times are resolved by ZonedDateTime.of. A non-existent time (spring) is shifted forward by the length of the gap; an ambiguous time (autumn) takes the first occurrence.

activeUntil method

End of the active period formed by schedules around now, chaining contiguous ranges (for example 22:00–00:00 then 00:00–06:00 → 06:00).
