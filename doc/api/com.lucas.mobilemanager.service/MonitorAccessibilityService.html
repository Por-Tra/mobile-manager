MonitorAccessibilityService class

Package: com.lucas.mobilemanager.serviceModule: :appSource: MonitorAccessibilityService.kt

Source of truth for the foreground app. Reads only the package name of the window, never its content. Delegates the decision to EnforcementCoordinator and enforces the block.
