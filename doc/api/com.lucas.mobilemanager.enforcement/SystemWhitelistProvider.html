SystemWhitelistProvider class

Package: com.lucas.mobilemanager.enforcementModule: :appSource: SystemWhitelistProvider.kt

Apps that must never be blocked. Resolved through the system rather than hard-coded, because package names differ between manufacturers (Samsung in particular).
