Schedule data class

Package: com.lucas.mobilemanager.domain.modelModule: :core:domainSource: Profile.kt

Weekly time range.

  • end <= start: the range crosses midnight; days are the days of the start.
  • start == end: 24-hour range. Start included, end excluded.
