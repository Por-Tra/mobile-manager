ProtectedScreenDetector object

Package: com.lucas.mobilemanager.domain.sessionModule: :core:domainSource: ProtectedScreenDetector.kt

During a session (or while a trusted person code locks the app), closes the screens that would make it possible to turn Mobile Manager off: any Settings or package installer screen that shows the app name (app info, accessibility service page, device admin, uninstall…).

Accepted side effect: a list that shows Mobile Manager (apps, accessibility) is closed too while the entry is visible.
