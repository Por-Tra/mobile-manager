DiagnosticOverlay class

Package: com.lucas.mobilemanager.diagnosticModule: :appSource: DiagnosticOverlay.kt

Diagnostic mode banner, shown by the accessibility service (TYPE_ACCESSIBILITY_OVERLAY: no extra permission). Can be dragged with a finger. Classic Android views: Compose would require a lifecycle that a service does not have.
