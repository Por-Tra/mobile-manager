ForegroundTracker class

Package: com.lucas.mobilemanager.domain.foregroundModule: :core:domainSource: ForegroundTracker.kt

Deduces the app really in the foreground from window changes.

Only activity windows count: the Google feed left of the home screen, widgets, the notification shade or the keyboard open windows that belong to other packages without the user having left the current app (or the home screen).
