HomePanels object

Package: com.lucas.mobilemanager.domain.foregroundModule: :core:domainSource: HomePanels.kt

Screens that are part of the home screen even though they belong to another app: the Google feed (“Discover”, left of the home screen) on recent Pixel launchers is a real activity of the Google app, embedded in the launcher task. Opening that panel must not count as “opening the Google app”.

On most launchers (One UI included), these panels are plain windows and are already ignored by ForegroundTracker because they are not activities. To add one: read the package and class in adb logcat -s MobileManager (“window” line).
