Build and test

Commands to build, test and install the app, and the procedures used to test on the emulator and on the real phone.

Commands

The system JDK (25) is too recent: use the JBR 21 shipped with Android Studio.

Bash
export JAVA_HOME="/c/Program Files/Android/Android Studio/jbr"
./gradlew :core:domain:test        # domain unit tests
./gradlew assembleDebug            # app/build/outputs/apk/debug/app-debug.apk
./gradlew lint                     # app/build/reports/lint-results-debug.html
./gradlew installDebug             # on the connected emulator or phone

Conventions

  • Conventional Commits (feat(zones): …, fix: …), at least one clean commit per phase.
  • Business logic is pure and tested in :core:domain; time always goes through TimeProvider.
  • UI texts only in res/values/strings.xml, in French, neutral or encouraging; never an aggressive red for a reached limit.
  • Versions are centralised in gradle/libs.versions.toml.

Emulator

Bash
export MSYS_NO_PATHCONV=1   # Git Bash: otherwise /sdcard/... becomes a Windows path
P=com.lucas.mobilemanager
adb shell settings put secure enabled_accessibility_services $P/$P.service.MonitorAccessibilityService
adb shell appops set $P GET_USAGE_STATS allow
adb shell dumpsys deviceidle whitelist +$P
adb shell appops set $P SYSTEM_ALERT_WINDOW allow
adb shell pm grant $P android.permission.POST_NOTIFICATIONS
adb shell dpm set-active-admin $P/.admin.MobileManagerAdminReceiver

Test daily limits after a cold boot (-no-snapshot-load): after a snapshot restore the usage service is out of sync and queryEvents() returns nothing. If installing fails with INSUFFICIENT_STORAGE: adb shell pm trim-caches 999G.

Real phone (Galaxy A04s)

  • After adb install -r or a force stop, the service may stay bound but silent (no window … log when opening an app). Sign: dumpsys accessibility shows the class name instead of the label “Surveillance Mobile Manager”. Fix: delete the enabled_accessibility_services setting, wait 3 s, put it again (sometimes twice).
  • uiautomator dump fails while a video plays; pause it, or rely on the debug log … zone reels signal N [ids]. Disable the service while capturing, otherwise it leaves the zone first.
  • No sqlite3 on the phone: adb exec-out run-as com.lucas.mobilemanager cat databases/mobile_manager.db (and the -wal file), then read it with Python.
  • CPU: /proc/<pid>/stat (fields 14 + 15) around a scripted scroll; profiling with simpleperf record --app com.lucas.mobilemanager on a debug build.
  • Instagram dumps: keep identifiers only (no message text, no names) and delete screenshots after use.

Debug logs: adb logcat -s MobileManager prints each evaluation (package usage=… -> Decision). Debug test tools: Settings › “Créer le profil Test” (24/7, Chrome limited to 1 min, YouTube blocked) and 1–2 min quotas.

Unit tests

Domain tests cover the rule engine, schedules (midnight, daylight saving, weekdays), profile resolution, focus sessions, foreground tracking, usage computation, zone matching against real captures, zone time accounting, the dashboard and the lock policy. They are listed under :core:domain (tests) in the source files, and appear in the Referenced in tables of the API reference with a test tag.

This documentation

The site is generated from the code by a dependency-free Python script:

Bash
python doc/tools/gen_docs.py                  # regenerate doc/
python doc/tools/gen_docs.py --missing out.txt  # list documentation comments without English translation
  • doc/tools/kotlin_parser.py recognises declarations, KDoc, annotations, constructor properties and nesting.
  • doc/tools/pages/*.html are the hand-written articles (this page included); {{Type}} placeholders become links to the reference.
  • doc/tools/kdoc_en.txt holds English translations of the KDoc comments, which are written in French in the code. A comment without translation is shown in French with a notice.
  • doc/assets/ contains the style sheet and the script (table of contents, search, copy); data.js is generated.

Open doc/index.html directly in a browser: no server is needed.
