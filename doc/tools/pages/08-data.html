Data and storage

Everything is stored locally, in a Room database and a DataStore preferences file. Nothing is backed up to a cloud and nothing leaves the phone.

Room database

{{MobileManagerDatabase}}. Enums are stored as text (their name), never as ordinals. Schemas are exported to core/data/schemas/ and committed; every change is an explicit migration.

Event journal

The event_log table records what the tool did, for the dashboard: {{EventType}} values APP_BLOCKED (detail such as profile:3, daily_limit:30, strict_session, global_rule), ZONE_REDIRECTED, focus session events and PROTECTION_DISABLED. Historical values (ZONE_VISIT, INTERSTITIAL_SHOWN, PAUSE_CLOSED_APP) are kept so older rows can still be read.
