Mobile Manager documentation

Mobile Manager is a personal Android app (installed outside the Play Store) that limits screen time “the hard way”: app blocking, daily limits and quotas, forbidden time ranges, focus sessions that cannot be stopped on a whim, and the removal of distracting zones such as Instagram Reels or YouTube Shorts while keeping the rest of the app usable.

Note

The user interface is in French and never guilt-inducing. Everything stays on the device: no account, no network access, no telemetry, and the content of messages or posts is never read (only the structure of the screen: view identifiers, tab labels, selection state).

Features

FeatureWhat it doesMain entry points
App blocking and limitsBlock an app, or allow it for a daily duration; time ranges where everything is blocked except explicit exceptions.RuleEngine, ProfileResolver, EnforcementCoordinator
ProfilesScheduled or manual sets of rules (Sleep, Study, Free time…), ordered by priority.Profile, ScheduleEvaluator, ProfileEditViewModel
Focus sessionsBlock chosen apps until an end time; stopping early requires a reflection delay chosen beforehand.StrictSessionManager, StrictSessionService
ZonesDetect Reels / Shorts inside an allowed app, leave them and hide their entry button.ZoneEnforcer, ZoneMatcher, EntryPointMask
QuotasCumulative daily time in a zone (for example 50 min of Reels) or in an app, then finished until midnight.ZoneUsageAccumulator, ZoneUsageRecorder
Trusted person codeChanges that loosen restrictions require a PIN; settings screens that could disable the app are closed while locked.AppLock, LockPolicy, PinHasher
DashboardScreen time per app and per day, comparison with the previous period, zone time and goals.DashboardCalculator, DashboardLoader
Diagnostic modeLive overlay showing the detected zone, tree capture, and an editor to repair detectors without a new build.DiagnosticOverlay, DiagnosticViewModel

Technology

  • Kotlin 2.4, Jetpack Compose with Material 3, MVVM with data / domain / ui layers.
  • Android Gradle Plugin 9.4 with built-in Kotlin, Gradle 9.8, KSP; minSdk 29, targetSdk 37.
  • Hilt, Room, DataStore, Navigation Compose with serializable routes, Coroutines and Flow, WorkManager.
  • Domain tests: JUnit 6 (Jupiter), Turbine, kotlinx-coroutines-test.
