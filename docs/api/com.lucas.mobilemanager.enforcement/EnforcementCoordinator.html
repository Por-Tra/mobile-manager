EnforcementCoordinator class

Package: com.lucas.mobilemanager.enforcementModule: :appSource: EnforcementCoordinator.kt

Connects the system (foreground app, usage) to the domain rule engine. It does not know the accessibility service: it decides, the service enforces.

Kotlin
@Singleton
class EnforcementCoordinator @Inject constructor(profileRepository: ProfileRepository, strictSessionRepository: StrictSessionRepository, manualActivationRepository: ManualActivationRepository, modeRepository: ModeRepository, preferencesRepository: com.lucas.mobilemanager.domain.repository.UserPreferencesRepository, @ApplicationScope appScope: CoroutineScope, private val profileResolver: ProfileResolver, private val ruleEngine: RuleEngine, private val timeProvider: TimeProvider, private val usageStatsReader: UsageStatsReader, private val whitelistProvider: SystemWhitelistProvider, private val eventLogRepository: EventLogRepository, private val zoneUsageRecorder: ZoneUsageRecorder)
